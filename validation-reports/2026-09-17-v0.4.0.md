# Validation report: 0.4.0

Milestone: the release that carries the fynedesygn adoption (spec 012) and the
reachable Cancel (spec 013).

## Scope

- Spec 012, adopt fynedesygn — merged earlier, reported in
  `2026-09-17-spec012-adopt-fynedesygn.md`. Closed since: AC9's manual run was
  re-done at the branch's final commit and the line counts corrected.
- Spec 013, a reachable Cancel during a build — `go.mod` to fynedesygn v0.1.4
  and `startBuild` handing `cancelBuild` to `shell.BusyCancellable`.

## Tests

`make test` (`go test -race -tags parity ./...`): all packages pass, including
`internal/gui` and `tests/parity`. No test was changed for spec 013: the
cancellation behaviour it reaches is the behaviour
`TestCancellingMarksOnlyTheRunningStep` and `TestPressingCancelDisablesItAtOnce`
already pin, and what is new is which button reaches it.

The join between the two — that the popup carries this program's cancel — is
covered on the library side by fynedesygn's
`TestBusyCancellablePutsTheJobsOwnCancelOnThePopup`, and on this side by a
manual press, because the popup exists only on screen while `testUI` is
headless on purpose (fyne quirk 11: the test driver runs `fyne.Do` inline, so
an on-screen build would race the test driving it).

## Manual verification

A window under a throwaway HOME, XDG and Steam root, with the real game
archives symlinked read-only and the real MBINCompiler copied in: Build
pressed, the popup's Cancel pressed. The running step was marked cancelled,
the banner reported the previous output put back, and the button was dead once
pressed.

## Code quality

`make lint` (golangci-lint v2.12.2): 0 issues. `go vet ./...`: clean. The
change is one call site; nothing was extracted or refactored around it.

## Release safety

- Rollback: `git revert` of the spec 013 commit returns `startBuild` to
  `shell.Busy` and `go.mod` to fynedesygn v0.1.3. The previous binary reads the
  same configuration and the same preference keys.
- Additive: no operation, flag or configuration key removed. The toolbar's
  Cancel is still there and still works before the popup appears.
- The library bump is a patch release of a v0 module the same author
  maintains; its own CI is green on Linux, macOS and Windows at v0.1.4.

## Security

`govulncheck -mode binary` on `nmsbonker` and `nmsbonker-gui`: no
vulnerabilities. No new dependency; `go mod tidy` left the `golang.org/x/*`
modules at the versions raised above Fyne's pins. No credentials, no network
call added, nothing written outside the paths the program already documents.
