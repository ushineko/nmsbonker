# nmsbonker

**Version**: 0.1.0 (pre-release, under construction)

No Man's Sky mod builder and trainer for Linux. Rebuilds AMUMSS-format `.lua`
mod scripts against the game files you actually have installed, merges every
enabled mod into one collision-free mod folder, and deploys it. Native Go: no
Wine, no Windows VM, no Python.

See `specs/` for the design of record. The README is completed in spec 004.
